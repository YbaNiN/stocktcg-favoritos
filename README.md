# StockTCG favoritos

Lista de productos favoritos de la web-app [Stock TCG](https://ybanin.github.io/stocktcg-alertas/).
La edita la propia app al pulsar el corazón, y el monitor de
[stocktcg-alertas](https://github.com/YbaNiN/stocktcg-alertas) la lee para avisar con prioridad urgente.

Está separada del repositorio principal a propósito: la clave que usa la app solo puede escribir aquí.
